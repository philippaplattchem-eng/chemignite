Working for selected MCQs

QReasoning
156Fe: mass number = 56, atomic number = 26. Protons = 26; neutrons = 56 − 26 = 30; electrons = 26 (neutral atom). Answer: A.
3RAM = (0.750 × 35) + (0.250 × 37) = 26.25 + 9.25 = 35.5. Answer: B.
4n = m/M = 5.6/56.0 = 0.10 mol. Answer: A.
6Al3+ and SO42−: to balance charges, 2 Al3+ (+6 total) needs 3 SO42− (−6 total) → Al2(SO4)3. Answer: B.
9AgBr is a cream/pale yellow precipitate. AgCl is white; AgI is yellow. Answer: C (Br−).
14C: 85.7/12.0 = 7.14; H: 14.3/1.0 = 14.3. Ratio 7.14 : 14.3 = 1 : 2 → empirical formula CH2. Answer: A.
15200 cm3 = 0.200 dm3. c = 0.040/0.200 = 0.20 mol dm−3. Answer: B.
16Multiplier = 180/30 = 6. Molecular formula = 6 × CH2O = C6H12O6. Answer: D.
